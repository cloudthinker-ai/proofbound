# Proofbound 0.1.0

First experimental release of proof contracts for Rust and Python, inspired by
Guillermo Rauch's [gdp-ts](https://github.com/rauchg/gdp-ts), Matt Noonan's Ghosts
of Departed Proofs and Ollie Charles's authorization research.

Sensitive operations can require evidence from their trusted issuer for the
exact named arguments they consume. Rust provides scoped generative types and
opaque runtime identities. Python verifies issuer, ordered subjects and active
scope before synchronous or asynchronous function execution.

Python includes a decorator, scoped names, typed consumers checked with mypy
and Pyrefly, and an AST linter for common issuance/export and bypass mistakes.
SQLite and FastAPI integration tests exercise real checks and protected writes.

The Python distribution is `gdp-rs`, import package `gdp`, command `gdp-lint`.
The Rust crate remains `gdp` and is available through the Git repository.
No crates.io publication is part of this release.

Release wheels target Linux x64/ARM64 (glibc 2.17+), macOS ARM64 (11+), and
Windows x64 using CPython's 3.11 stable ABI. CI tests CPython 3.11–3.14.
Source installation needs Rust 1.90 or newer.

Install [gdp-rs 0.1.0 from PyPI](https://pypi.org/project/gdp-rs/0.1.0/):

```bash
pip install gdp-rs==0.1.0
```

The API may change within the 0.1 series. Proofs record check-time facts; they
do not establish correct application policy or atomic check-and-write behavior.
See [guarantees](../guarantees.md) and [security reporting](../../SECURITY.md).
